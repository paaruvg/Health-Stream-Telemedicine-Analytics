# Health-Stream-Telemedicine-Analytics
Group Project

Health Stream – Telemedicine Analytics and Healthcare Management System

Introduction

Health Stream – Telemedicine Analytics and Healthcare Management System aim to help patients and healthcare providers manage online consultations, appointments, medical records, and healthcare analytics on a single platform.
The platform includes user login functionality for patients, doctors, and administrators. Patients can book appointments and access their medical records; doctors can manage consultations and patient records. The administrator will monitor healthcare activities and generate analytics reports.

<b>Problem Statement</b>

Traditional healthcare systems face delays in processing and monitoring patient data. Telemedicine applications require real-time data streaming and analysis for effective patient monitoring. Handling large volumes of healthcare data efficiently is a major challenge. Existing systems often lack scalability, real-time analytics, and centralized monitoring capabilities. This project aims to develop a real-time healthcare data engineering pipeline using Apache Kafka, SQL Server, and Power BI to improve healthcare data streaming, storage, and visualization.
